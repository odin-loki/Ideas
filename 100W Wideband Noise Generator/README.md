## 📡 Overview

**100W Wideband Noise Generator** provides a complete specification for a 100W wideband RF noise generator using Chua chaos circuits under FPGA control. This work combines chaos theory with hardware implementation for RF noise generation.

### Key Concepts

- **Chua Chaos**: Chaotic circuit dynamics for noise generation
- **FPGA Control**: Field-programmable gate array for waveform control
- **Wideband RF**: Broadband radio frequency generation
- **100W Output**: High-power noise generation
