# Compression Algorithms — Structured Information Reduction

> **📦 Overview**: **GRIA**, **NMP**, a stab at a unified compression story, and **Izaac** cross-links — not just "smaller blobs," but structured side information.

---

## 📦 Overview

**Compression Algorithms** explores compression beyond simple lossless reduction to structured information representation. This work includes the GRIA (Generalised Random Information Algorithm), NMP (Neural Multi-Precision) framework, and Izaac cross-links for auxiliary channel compression.

### Key Concepts

- **GRIA**: Generalised Random Information Algorithm
- **NMP**: Neural Multi-Precision compression
- **Izaac**: Auxiliary channel compression
- **Structured Information**: Beyond bit reduction to semantic compression
