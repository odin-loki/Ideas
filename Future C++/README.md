# Future C++ — Language Design as Conversation

> **🔮 Overview**: A running log of **C++** futures that might never ship — language design as conversation, no package yet.

---

## 🔮 Overview

**Future C++** serves as a running log exploring potential C++ language features that might never make it to standardisation. This work treats language design as an ongoing conversation — documenting proposals, discussions, and speculative ideas.

### Key Concepts

- **Language Futures**: Potential C++ features under consideration
- **Design Conversation**: Documenting proposal discussions
- **Speculative Ideas**: Features that may never ship
- **Learning Resource**: Educational examples of language design
