# NN Shortcuts — Streaming Geometry and Shortcut Paths

> **⚡ Overview**: Streaming geometry and shortcut paths — making depth cheap where the manifold allows it.

---

## ⚡ Overview

**NN Shortcuts** explores neural network architectures that use shortcut connections and streaming geometry to reduce computational depth. This work enables efficient neural network designs that maintain performance while reducing computational cost.

### Key Concepts

- **Shortcut Connections**: Bypassing layers to reduce depth
- **Streaming Geometry**: Flowing data through efficient pathways
- **Depth Reduction**: Making networks shallow where possible
- **Manifold-Aware**: Exploiting geometric structure
