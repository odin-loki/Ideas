## What this folder is

This folder holds **standalone threat-intelligence monographs** — distinct from the systems-engineering specs in [`../Weapons-Defence/`](../Weapons-Defence/). Each report follows an executive-summary → mechanism → plausibility → countermeasures structure suitable for red-team, EOD, or counter-intelligence readers. Assessments are **hypothetical**: they reason from published science, historical program context, and open-source tradecraft patterns without claiming confirmed operational deployment.

The folder name is spelled **`Threat Asessments`** (missing the second “s” in “Assessments”) in the repository path; links and indexes use that spelling so paths resolve on Git and locally.
