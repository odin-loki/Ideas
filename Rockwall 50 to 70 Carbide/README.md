# Rockwall 50 to 70 Carbide — Sintered Carbide Grades and Metallurgy

> **🔩 Overview**: Sintered carbide grades, forge-to-machine workflow, defence-side analysis — metallurgy with a use case.

---

## 🔩 Overview

**Rockwall 50 to 70 Carbide** explores sintered carbide grades, particularly those with tungsten carbide grain sizes in the 50-70 micron range. This work covers metallurgy, processing, and defence applications including ADF (Australian Defence Force) considerations.

### Key Concepts

- **Sintered Carbide**: Tungsten carbide particles bonded with cobalt or nickel
- **Grain Size Control**: Precise control over WC grain size (50-70 microns)
- **Forging to Machine**: Net shape forging followed by finishing
- **Defence Applications**: Military cutting tools and components
