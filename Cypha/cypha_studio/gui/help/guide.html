Getting started

  1. Import data — File → Import Dataset… or the Dataset panel. CSV, NPY, and NPZ are supported; sklearn quick-load buttons are available for demos.
  2. Load or train a model — File → Open Model… from the registry, or train from the toolbar after configuring training.
  3. Chat — Enter a comma-separated feature vector (or text if the pipeline supports it). Use Ctrl+Enter or Enter to send.

Dataset & splits

The Dataset dock has two load paths: Your data (your CSV/NPY/NPZ files) and Demo datasets (small sklearn toy sets for trying the UI only). Statistics and class balance appear below. Train / validation / test percentages must leave at least 5% for test. Adjust shuffle, stratification (classification only), and random seed; changes re-split the loaded data automatically.

Large CSV files can be streamed in chunks via Studio Settings → Paths & data or the CYPHA_CSV_CHUNK_ROWS environment variable.

Training

Train → Configure… opens the full hyperparameter dialog (tabs: model & encoder, optimization, schedule & preprocessing). Train → Start Training runs in the background; monitor the Training dock.

  • Mode — online vs batch affects how samples are consumed.
  • GH protection — Adversarial-style regularization during training (separate from GH inference in chat).
  • Preprocessing — Scale and optional PCA components are applied when the trainer builds the preprocessor.

Inference & chat

GH inference (classification) routes through gh_infer with session parameters χ and ψ. You can turn GH off to use the standard infer path.

OOD threshold — Inputs with anomaly score above the threshold are flagged as out-of-distribution in the UI.

Regression tasks use posterior-style uncertainty in the chat bubble; GH toggles mainly affect classification.

Studio settings

File → Settings… persists choices in Qt QSettings under Cypha/CyphaStudio.

  • Inference — GH on/off, OOD threshold, χ and ψ.
  • Paths & data — Optional registry root override, CSV chunk size override, default folder for dataset file dialogs.
  • Appearance — Optional application font size (points).
  • Environment — Read-only summary of REST defaults and CYPHA_* variables. GUI overrides for registry and CSV chunks are ignored when left empty/zero; then environment defaults apply.

Shortcuts & views

  • Ctrl+Enter — Send chat message
  • Ctrl+L — Focus chat input
  • View menu — Show or hide docks (Training, Dataset, Experiments, Studio Log, User Guide)
  • View → Reset Layout — Show all docks
