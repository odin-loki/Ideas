# PREP & WORKFLOW SYSTEM

## DAILY PREP SCHEDULE

### Morning Prep (Start of Shift)
1. Check all blends & infusions
   - Test each syrup for consistency
   - Check infusion progress
   - Strain any completed infusions
   - Start new batches as needed

2. Fresh Elements
   - Cut garnishes
   - Prepare herb sprigs
   - Make fresh juices
   - Prep fruit for service

3. Bar Setup
   - Fill ice wells
   - Check carbonation levels
   - Prep garnish stations
   - Test all soda guns

### Mid-Day Tasks
1. Restock as needed
   - Check garnish levels
   - Top up ice
   - Rotate bottles
   - Clean prep areas

2. Quality Control
   - Taste test all syrups
   - Check infusion progress
   - Verify carbonation levels
   - Test new batches

### End of Night
1. Strain all infusions
2. Date all prepped items
3. Clean all tools
4. Log inventory used

## EFFICIENCY GUIDELINES

### Mise en Place
1. Primary Stations
   - All syrups within reach
   - Garnishes prepped
   - Tools organized
   - Fresh ingredients ready

2. Secondary Station
   - Backup supplies
   - Extra garnishes
   - Clean tools
   - Fresh ice

3. Prep Area
   - Clearly labeled storage
   - Dated containers
   - Organized shelves
   - Clean workspace

### Cross-Utilization
1. Syrup Usage
   - Multiple cocktails
   - Non-alcoholic drinks
   - Food menu items
   - Staff training

2. Garnish Prep
   - Zero waste goal
   - Multiple applications
   - Creative reuse
   - Preservation methods

3. Tool Usage
   - Efficient placement
   - Multiple purposes
   - Easy cleaning
   - Quick replacement

### Quality Control
1. Daily Checks
   - Taste all syrups
   - Check garnishes
   - Verify infusions
   - Test carbonation

2. Weekly Checks
   - Full inventory
