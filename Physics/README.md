## 🌌 What's actually being proposed

Three structural commitments run through all three papers:

1. **Non-locality as a primitive.** Both advanced ($K_{\text{adv}}$) and retarded ($K_{\text{ret}}$) kernels enter the field equations symmetrically, integrated over a 4D source distribution $\rho(x')$.
2. **Multiplicative kernel composition.** The master kernel factorises as $K_{\text{base}}\prod(1+K_i)\exp(\sum S_{ij})$, allowing each subtle / network contribution to enter as a small-correction product term plus an exponential interaction sum.
3. **Hierarchical decomposition.** $\phi$ is split into fundamental ($\phi_f$), emergent ($\phi_e$), interaction ($\phi_{\text{int}}$), subtle ($\phi_{\text{subtle}}$), and network ($\phi_{\text{network}}$) layers — gravity is the *first* layer, not the only one.

> Earlier README copy advertised a "key results" table with bullet-point claims; the actual papers are derivations rather than result tabulations, and the most useful entry point is the master framework's field decomposition theorem.

## 🚧 Honest framing

- **Speculative theoretical physics.** None of these frameworks has experimental backing. The non-local kernel approach has historical precedent (Wheeler-Feynman absorber theory, etc.) but the specific decomposition + multiplicative-kernel structure here is the author's own.
- The NLFGN acronym is read as Non-Local Field Gravity / Network in this folder; it is unrelated to any other use of the abbreviation in the literature.
- "Big equations, explicit assumptions" — but the assumptions are still the author's, not derived from data. Read as a research programme, not as a unification result.
