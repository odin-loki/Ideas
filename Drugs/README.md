## 🧪 Overview

**Drugs** explores speculative pharmaceutical research and depot delivery narratives, including subfolders for nootropics and schizophrenia cure research. This collection treats drug delivery systems as a design challenge — exploring how compounds can be engineered for sustained release, targeted delivery, and minimised side effects.

### Key Concepts

- **Depot Delivery**: Creating reservoirs that release compounds over extended periods
- **TriPhase Performance**: Multi-stage release profiles for sustained therapeutic effect
- **Injectable Nutrition**: Food-grade compounds delivered parenterally
- **Sugar-Based Excipients**: Using sugar matrices as sustained-release vehicles

## 🔬 Research Themes

### Depot Delivery Systems

- **Matrix Formulation**: Creating polymeric matrices for controlled release
- **Encapsulation**: Enclosing active compounds in biocompatible shells
- **Stimuli-Responsive**: Release triggered by physiological signals
- **Multi-Compartment**: Multi-stage release from layered structures

### Injectable Nutrition

- **Caloric Density**: Maximising nutrients per volume
- **Absorption Profile**: Optimising uptake in various tissues
- **Stability**: Maintaining compound integrity during storage and delivery
- **Safety**: Ensuring biocompatibility and minimising adverse reactions

### Nootropic Systems

- **Blood-Brain Barrier Penetration**: Engineered delivery across barriers
- **Cognitive Targeting**: Directing effects to specific neural circuits
- **Duration Tuning**: Adjusting effect duration for different use cases
- **Stacking**: Combining compounds for synergistic effects
