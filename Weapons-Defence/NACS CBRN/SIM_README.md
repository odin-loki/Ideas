# NACS CBRN — Simulation Coverage

**No standalone simulator.** NACS-TOTAL has no dedicated Python simulation package and no Tier-2 section in [`../weapons_simulation.py`](../weapons_simulation.py).

---

## Where the numbers come from

All quantitative claims in this platform — camouflage percentages, IR reduction, CBRN protection duration, antimicrobial persistence, 72-hour operational envelope, cost analysis — are **prose engineering estimates** in [`NACS_Specification.md`](NACS_Specification.md) and [`NACS_Research_Paper.md`](NACS_Research_Paper.md).

They are **not** regenerated by running `python weapons_simulation.py`.
