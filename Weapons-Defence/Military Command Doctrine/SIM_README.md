# Military Command Doctrine — Simulation Coverage

**No simulation.** The Adaptive Command Military Doctrine is a **non-physical, doctrinal** platform. [`../weapons_simulation.py`](../weapons_simulation.py) does **not** model:

- Command-and-control structures
- Force-on-force outcomes
- Training pipeline throughput
- Unit-cost or personnel economics
- Succession-of-command effectiveness

No standalone simulator exists in this folder and no Tier-2 section in the portfolio script covers doctrine.

---

## Local verification script

[`platform_simulation.py`](platform_simulation.py) runs the portfolio engine ([`../weapons_simulation.py`](../weapons_simulation.py)) via [`../sim_common.py`](../sim_common.py) and prints the platform-specific verification slice for this folder. For Military Command Doctrine, the script **documents scope limits only** — tier sizes, training durations, and force-structure economics are prose targets, not physics-sim outputs.

```bash
python platform_simulation.py
```

To regenerate the full portfolio results file, still run:

```bash
cd ..
python weapons_simulation.py
```

---

## Where the numbers come from

All quantitative claims — tier sizes (5 / 25 / 100 / 1,000 / 50,000), training durations (16 + 12 + 8 weeks), skills allocation (40/30/20/10) — are **prose doctrinal targets** in:

- [`Command_Doctrine_Specification.md`](Command_Doctrine_Specification.md)
- [`Command_Doctrine_Research_Paper.md`](Command_Doctrine_Research_Paper.md)

They are not regenerated by running `python weapons_simulation.py`.
