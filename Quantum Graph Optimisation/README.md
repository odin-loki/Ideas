## 🔺 Overview

**Quantum Graph Optimisation** explores quantum graph theory and its applications to quantum computing. This work combines graph theory with quantum computation to develop optimisation algorithms that leverage quantum advantages.

### Key Concepts

- **Quantum Walk**: Quantum superposition on graph edges
- **Graph State**: Quantum states representing graph structure
- **Optimisation**: Solving optimisation via quantum paths
- **Python Reference**: Accessible implementation reference
