# Math Question Generator — Structured Question Generation

> **🎓 Overview**: A broad mathematics survey plus **Math-Gen** tooling — generating hard, structured questions, not trivia.

---

## 🎓 Overview

**Math Question Generator** explores mathematics education and assessment through structured question generation. This work includes the Math-Gen tooling for creating rigorous, well-structured mathematical questions that test genuine understanding rather than trivia memorisation.

### Key Concepts

- **Structured Questions**: Questions with defined solution paths
- **Difficulty Tuning**: Controlling question difficulty
- **Topic Coverage**: Broad mathematical domain coverage
- **Answer Verification**: Automated solution verification

## 💡 Design Principles

1. **Single Solution**: Each question has one correct answer
2. **Verifiable**: Solutions can be automatically verified
3. **Educational**: Designed to teach, not just test
4. **Scalable**: Can generate questions at scale
5. **Difficulty-Ranked**: Questions sorted by difficulty
