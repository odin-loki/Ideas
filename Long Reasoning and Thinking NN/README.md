## 🧠 Overview

**Long Reasoning and Thinking NN** explores neural networks designed for extended reasoning chains and long planning horizons. This work includes the UHPM (Unified Hypothesis Planning Machine) and related long-thought architectures that enable systems to reason across extended time scales.

### Key Concepts

- **Long Reasoning**: Extended chains of thought spanning many inference steps
- **Planning Horizon**: Networks that plan far ahead
- **UHPM**: Unified Hypothesis Planning Machine
- **Memory Integration**: Access to historical context
