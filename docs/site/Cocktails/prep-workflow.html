DAILY PREP SCHEDULE

Morning Prep (Start of Shift)

  1. Check all blends & infusions - Test each syrup for consistency - Check infusion progress - Strain any completed infusions - Start new batches as needed

  2. Fresh Elements - Cut garnishes - Prepare herb sprigs - Make fresh juices - Prep fruit for service

  3. Bar Setup - Fill ice wells - Check carbonation levels - Prep garnish stations - Test all soda guns

Mid-Day Tasks

  1. Restock as needed - Check garnish levels - Top up ice - Rotate bottles - Clean prep areas

  2. Quality Control - Taste test all syrups - Check infusion progress - Verify carbonation levels - Test new batches

End of Night

  1. Strain all infusions
  2. Date all prepped items
  3. Clean all tools
  4. Log inventory used

WEEKLY PREP SCHEDULE

Monday

  • Start new infusions
  • Prep base blends
  • Deep clean stations
  • Inventory check

Tuesday

  • Make fresh syrups
  • Start new tinctures
  • Prep garnish elements
  • Order supplies

Wednesday

  • Check all infusions
  • Rotate stock
  • Deep clean tools
  • Staff training

Thursday

  • Prep weekend batches
  • Make fresh blends
  • Stock garnishes
  • Equipment check

Friday-Sunday

  • Focus on service
  • Essential prep only
  • Quick restocks
  • Basic maintenance

MONTHLY TASKS

Week 1

  • Deep clean everything
  • Full inventory
  • Staff training
  • Menu updates

Week 2

  • Start long infusions
  • Prep special events
  • Equipment maintenance
  • Order specialty items

Week 3

  • Rotate all stock
  • Check all dates
  • Clean storage
  • Staff meetings

Week 4

  • Menu testing
  • New recipe development
  • Deep clean again
  • Planning next month

EFFICIENCY GUIDELINES

Mise en Place

  1. Primary Stations - All syrups within reach - Garnishes prepped - Tools organized - Fresh ingredients ready

  2. Secondary Station - Backup supplies - Extra garnishes - Clean tools - Fresh ice

  3. Prep Area - Clearly labeled storage - Dated containers - Organized shelves - Clean workspace

Cross-Utilization

  1. Syrup Usage - Multiple cocktails - Non-alcoholic drinks - Food menu items - Staff training

  2. Garnish Prep - Zero waste goal - Multiple applications - Creative reuse - Preservation methods

  3. Tool Usage - Efficient placement - Multiple purposes - Easy cleaning - Quick replacement

Quality Control

  1. Daily Checks - Taste all syrups - Check garnishes - Verify infusions - Test carbonation

  2. Weekly Checks - Full inventory - Recipe testing - Staff training - Deep cleaning

  3. Monthly Checks - Menu updates - Equipment maintenance - Staff evaluation - Process improvement
