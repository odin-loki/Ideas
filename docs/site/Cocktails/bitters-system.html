UNIVERSAL BITTERS SYSTEM

BASE FORMULA TEMPLATE

Core Ratio (500ml Batch)

  • 375ml high-proof neutral spirit (minimum 50% ABV)
  • 75g primary flavoring agent
  • 25g bittering agents
  • 25g supporting spices
  • 50ml filtered water (for dilution)

Standard Bittering Agents (Choose 2-3)

  • Gentian root (12g)
  • Wormwood (8g)
  • Quassia bark (5g)
  • Angelica root (5g)

Extraction Timeline

  1. Primary Infusion (Day 1-7)
    - Add primary flavoring to spirit
    - Store in dark glass
    - Shake daily
    - Strain at day 7

  2. Bittering Phase (Day 8-14)
    - Add bittering agents
    - Continue daily agitation
    - Strain at day 14

  3. Spice Integration (Day 15-21)
    - Add supporting spices
    - Final week infusion
    - Strain and filter

  4. Finishing (Day 22)
    - Dilute to taste
    - Fine strain
    - Bottle and age 1 week

PROCESS GUIDELINES

Preparation

  1. Ingredients
    - Use dried botanicals when possible
    - Fresh citrus must be dried first
    - Crush whole spices lightly
    - Precise measurements

  2. Spirit
    - Minimum 50% ABV
    - Neutral flavor
    - Room temperature
    - Clean glass container

Daily Maintenance

  1. Morning
    - Gentle agitation
    - Visual inspection
    - Aroma check
    - Temperature check

  2. Evening
    - Second agitation
    - Note changes
    - Check seals
    - Adjust storage

Filtration Steps

  1. First Pass
    - Coarse strain
    - Remove large solids
    - Save botanicals
    - Clean container

  2. Second Pass
    - Coffee filter
    - Slow drip
    - Clear liquid
    - No sediment

  3. Final Filter
    - Fine paper filter
    - Complete clarity
    - Bottle immediately
    - Label clearly

QUALITY CONTROL

Testing Points

  1. Week 1
    - Taste test
    - Color check
    - Aroma evaluation
    - Clarity check

  2. Week 2
    - Bitterness level
    - Integration check
    - Secondary notes
    - Texture test

  3. Week 3
    - Final balance
    - Dilution test
    - Dropper test
    - Recipe notes

Storage Guidelines

  1. Short Term
    - Dark bottles
    - Cool place
    - Standing upright
    - Away from light

  2. Long Term
    - Sealed caps
    - Temperature stable
    - Regular checks
    - Sample testing

Troubleshooting

  1. Too Bitter
    - Increase dilution
    - Reduce bitter agents
    - Add supporting spices
    - Note for next batch

  2. Too Weak
    - Extended infusion
    - Increase botanicals
    - Reduce dilution
    - Check spirit proof

  3. Cloudy Result
    - Additional filtering
    - Let settle longer
    - Finer filter paper
    - Check botanicals
