CORE RATIO SYSTEM (500ml Batch)

Base Spirit Mix

  • 400ml high-proof neutral spirit (60%+ ABV)
  • 100ml filtered water (for final dilution)

Four-Part Botanical Structure

Each category should total the specified weight, mixed from the options listed:

  1. Primary Bittering Agents (50g total) Choose 3-4: - Gentian root (core bitter) - Quassia bark (sharp bitter) - Wormwood (complex bitter) - Angelica root (earthy bitter) - Horehound (medicinal bitter) - Dandelion root (soft bitter) - Chinchona bark (bright bitter) - Bitter orange peel (citrus bitter)

  2. Supporting Bitter Elements (25g total) Choose 2-3: - Calamus root - Yarrow - Oregon grape root - Yellow dock - Artichoke leaf - Blessed thistle - Centaury - Barberry bark

  3. Aromatic Bridge Elements (25g total) Choose 3-4: - Cassia bark - Ceylon cinnamon - Star anise - Green cardamom - Black cardamom - Grains of paradise - Cubeb berries - Wild cherry bark - Birch bark - Kola nut - Cocoa nibs - Coffee beans

  4. Top Note Elements (25g total) Choose 2-3: - Fresh citrus peel - Lemon myrtle - Kaffir lime leaves - Makrut lime peel - Fresh ginger - Galangal - Pink peppercorns - Szechuan peppercorns - Juniper berries - Fennel seed - Coriander seed

PHASED INFUSION PROCESS

Phase 1: Primary Bitters (Days 1-10)

  1. Combine in 500ml jar: - 300ml high-proof spirit - All primary bittering agents - Half of supporting bitter elements
  2. Store dark, shake daily
  3. Strain through cheesecloth
  4. Reserve liquid

Phase 2: Aromatics (Days 11-17)

  1. Add to strained liquid: - 100ml fresh high-proof spirit - All aromatic bridge elements - Remaining supporting bitters
  2. Continue dark storage
  3. Shake twice daily
  4. Strain through cheesecloth

Phase 3: Top Notes (Days 18-21)

  1. Add to strained liquid: - All top note elements
  2. Final dark storage
  3. Shake three times daily
  4. Triple filtration: - Cheesecloth - Fine mesh - Coffee filter

Phase 4: Finishing (Days 22-28)

  1. Final Filtration: - Let settle 24 hours - Decant carefully - Filter through paper
  2. Dilution: - Add 100ml filtered water - Rest 24 hours - Final filter if needed
  3. Aging: - Minimum 1 week - Dark storage - Room temperature

PRACTICAL TIPS

Ingredient Preparation

  1. Botanicals: - Crush roots lightly - Break bark into small pieces - Rough chop fresh ingredients - Use dried when possible

  2. Fresh Elements: - Remove citrus pith - Dry citrus peels - Grate fresh roots - Crush berries slightly

Equipment Needed

Essential: - 500ml glass jar - Fine mesh strainer - Coffee filters - Cheesecloth - Dark bottles - Digital scale - Funnels - Grater/zester

Optional: - pH strips - Filter papers - Dropper bottles - Botanical grinder

Storage Guidelines

Short Term: - Dark glass bottles - Cool, dark place - Vertical storage - Regular checks

Long Term: - Sealed containers - Temperature control - Monthly testing - Proper labeling

Scaling Notes

250ml Batch: - Halve all ingredients - Same timeline - Smaller containers - More frequent agitation

1L Batch: - Double all ingredients - Extended timeline (+3 days) - Larger containers - More filtration
