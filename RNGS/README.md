---

## 🎲 Overview

**RNGS** explores various random number generation techniques, from traditional linear congruential generators to more exotic approaches like turbulent flow and meta-DAG methods. This work examines the full zoo of RNG approaches, their theoretical properties, and practical applications.

### Key Concepts

- **LCG**: Linear Congruential Generator — classical approach
- **Meta-DAG RNG**: Meta-dependency acyclic graph RNG
- **Turbulent Flow RNG**: Chaos-based RNG using fluid dynamics
- **Transcendental LCG**: Beyond classical LCG approaches
